# SQL Analysis

This folder contains the SQL analysis used to build the analytical layer for the E-Commerce Customer Growth Analytics project.

## Planned analysis modules

1. Order item summary
2. Order payment summary
3. Order review summary
4. Order summary
5. Customer summary
6. Customer first-order analysis
7. RFM customer segmentation
8. Customer retention analysis
9. Category retention analysis
10. Cohort retention analysis

The SQL is written for MySQL 8 and uses the Olist Brazilian E-Commerce Public Dataset.
