# Week 1 – Strategic Planning and Data Exploration

## Objective

The first week focused on defining a realistic logistics analytics problem and planning how data science could be used to improve operational decision-making.

## Scenario

The project considers a logistics operation where management wants to understand delivery performance, transportation cost and potential causes of late deliveries. The analysis is designed around shipment-level data and focuses on improving service reliability while controlling logistics cost.

## Key KPIs

- Average Delivery Time
- Late Delivery Rate
- Average Transportation Cost
- Shipment Volume
- Cost per Shipment

## Analytical Approach

The planned workflow covers data collection, data-quality checks, cleaning, exploratory analysis, visualization, predictive modeling and optimization. Python is the main analytical tool, with Pandas for data preparation and Matplotlib/Seaborn for visualization. Regression and tree-based models are considered for prediction, while optimization techniques can later be used for route and resource planning.

## Dataset Reference

The public reference dataset selected for the project is the DataCo Smart Supply Chain for Big Data Analysis dataset:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

The dataset was selected because it contains supply-chain and logistics-related information that can support analysis of delivery, shipping and operational performance.

## Deliverable

The Week 1 report documents the business scenario, KPIs, research, proposed data-science methods and end-to-end analytical roadmap.
