# YuvaIntern – Logistics Data Analytics

A four-week **Logistics Data Analytics internship project** completed as part of the YuvaIntern program.

The project follows an end-to-end analytics workflow covering strategic planning, data preparation, exploratory analysis, visualization, predictive modeling and logistics optimization.

## Project Progression

| Week | Topic | Main Work |
|---|---|---|
| Week 1 | Strategic Planning and Data Exploration | Defined the logistics problem, KPIs, data-science approach and analytical roadmap |
| Week 2 | Data Collection, Cleaning and Preprocessing | Built a reproducible Python preprocessing workflow for logistics data |
| Week 3 | Advanced Data Analysis and Visualization | Performed EDA and created logistics performance visualizations using a simulated dataset |
| Week 4 | Predictive Modeling and Optimization | Compared regression models for delivery-time prediction and connected predictions to logistics decisions |

## Business Problem

The project focuses on **delivery performance in logistics**, with analysis of delivery time, late deliveries, transportation cost, shipping mode, distance, shipment volume and regional performance.

Week 1 and Week 2 use the public **DataCo Smart Supply Chain for Big Data Analysis** dataset as the reference dataset. Week 3 and Week 4 use a controlled hypothetical logistics dataset so that the analysis and predictive-modeling workflow can be reproduced consistently.
