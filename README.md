# Data Analytics Portfolio

Welcome to my **Data Analytics portfolio**.

This repository contains practical analytics projects focused on turning raw business data into **actionable insights, analytical models and decision-ready dashboards**.

## About This Portfolio

My work combines:

- **SQL / MySQL** — data preparation, joins, aggregations, analytical modeling and validation

## Featured Projects

### 1. E-Commerce Customer Growth Analytics

**Tools:** MySQL 8 · Power BI · SQL · Python · RFM · Cohort Analysis

An end-to-end e-commerce analytics project using the **Olist Brazilian E-Commerce Public Dataset**.

The project analyzes:

- Revenue and order trends
- Customer acquisition and one-time vs repeat behavior
- Customer lifetime value and value bands
- RFM customer segmentation
- Product-category retention
- Cohort retention
- First-order retention drivers
- Business recommendations for improving repeat purchases

**Key findings:**

- 96,478 delivered orders
- 93,358 delivered customers
- 15.42M delivered gross order value
- 159.83 delivered AOV
- Approximately 3% overall repeat customer rate
- Strong opportunity to convert high-value one-time customers into repeat buyers

**Project:** [`E-Commerce Customer Growth Analytics`](E-Commerce%20Customer%20Growth%20Analytics/)

**Dashboard:** [`Power BI PBIX`](E-Commerce%20Customer%20Growth%20Analytics/dashboard/Ecommerce_Customer_Growth_Analytics.pbix)

**SQL:** [`SQL Analysis`](E-Commerce%20Customer%20Growth%20Analytics/sql/)

### 2. YuvaIntern – Logistics Data Analytics

**Tools:** Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn

A four-week logistics analytics internship project covering the complete analytics workflow from problem definition and KPI planning to data preprocessing, exploratory analysis, visualization, predictive modeling and optimization considerations.

The project focuses on delivery performance, late deliveries, transportation cost, shipping modes, distance, shipment volume and regional performance. Week 4 compares Linear Regression and Random Forest models for delivery-time prediction.
