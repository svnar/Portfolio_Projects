# Python Analysis

Python was used as a supporting analytical layer alongside MySQL and Power BI.

The Python work covered customer growth trends, customer lifecycle analysis, customer value bands, frequency-versus-value correlation, retention-driver statistical testing, and cohort-retention validation.

## Scripts

- `01_customer_growth_analysis.py` - customer growth, lifecycle, value-band and frequency/value analysis from MySQL.
- `02_retention_statistical_analysis.py` - statistical testing of retention drivers from exported analytical data.

## Dependencies

- pandas
- mysql-connector-python
- scipy

Database credentials are supplied through environment variables and are not stored in the repository.
