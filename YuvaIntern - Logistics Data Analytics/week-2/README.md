# Week 2 – Data Collection, Cleaning and Preprocessing

## Objective

Week 2 focused on preparing logistics data for analysis. The main emphasis was on understanding common data-quality problems and creating a structured preprocessing workflow in Python.

## Reference Dataset

The public reference dataset used in the project planning is the DataCo Smart Supply Chain for Big Data Analysis dataset:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

## Preprocessing Workflow

1. Load the dataset using Pandas.
2. Inspect rows, columns, data types and missing values.
3. Remove duplicate records where required.
4. Standardize column names and data types.
5. Handle missing numerical values using appropriate imputation methods.
6. Review outliers using descriptive statistics and IQR-based checks.
7. Convert categorical variables into analysis-ready representations.
8. Scale numerical variables where required for machine-learning models.
9. Export the cleaned dataset for later analysis.

## Why Data Quality Matters

Incorrect or inconsistent logistics data can directly affect KPIs, visualizations and predictive models. The preprocessing stage therefore acts as a quality-control step before analysis. Cleaning decisions should be documented rather than changing records without a reason.

## Deliverable

The Week 2 report explains the collection simulation, data-quality checks, missing-value handling, outlier review, normalization/preprocessing and Python implementation approach.
