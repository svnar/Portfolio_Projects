# Week 3 – Advanced Data Analysis and Visualization

## Objective

Week 3 moved from data preparation into exploratory data analysis. The aim was to understand logistics performance, identify relationships between operational variables and communicate the findings through clear visualizations.

## Dataset

A hypothetical logistics dataset containing 1,200 shipment records was used for this exercise, as the assignment explicitly permits a simulated dataset. The dataset contains region, shipping mode, product category, shipment volume, distance, delivery time, transportation cost, shipment value and late-delivery status.

## Analysis Performed

- Descriptive statistics and central-tendency analysis
- Delivery-time distribution
- Late-delivery analysis by shipping mode
- Transportation cost versus distance
- Correlation analysis
- Regional performance comparison

## Tools

Python, Pandas, Matplotlib and Seaborn.

## Key Questions

- How are delivery times distributed?
- Which shipping modes show higher late-delivery rates?
- How does transportation cost change with distance?
- Which variables show relationships that may be useful for later modeling?

The analysis was designed to lead naturally into Week 4, where delivery time is used as the target variable for predictive modeling.
